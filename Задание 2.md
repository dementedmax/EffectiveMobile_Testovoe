## 1. Пример REST API запроса

Для такого экрана логично сделать отдельный endpoint получения списка партнерских магазинов.

```
GET /api/v1/partner-stores
Host: api.petrushka-green.ru
Authorization: Bearer <token>
Accept: application/json
```

Это минимальный вариант, но лучше сразу заложить дополнительные query-параметры:

```
GET /api/v1/partner-stores?city_id=12&limit=10
```

Где:
- `city_id` — идентификатор города пользователя;
- `limit` — ограничение количества магазинов.

Их лучше добавить с целью возможности дальнейшего масштабирования, в случае если бизнес решить расшириться на другие города.
