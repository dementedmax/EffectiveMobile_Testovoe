### Проблема 1

П.2:
> Пользователь может изменить количество каждого товара в корзине не менее, чем до 1-го. Для удаления товара используется отдельная кнопка.

П.9:
> Если пользователь уменьшает количество товара до 0, товар удаляется из корзины.

ТЗ одновременно запрещает уменьшать количество ниже 1 и допускает уменьшение до 0.  
Непонятно, какой сценарий считается корректным:
- пользователь вообще не может установить 0;
- пользователь может установить 0, и это эквивалент удаления;
- удаление только через кнопку.

Последствия:
- невозможно корректно реализовать UI/валидацию;
- разные разработчики реализуют разное поведение;
- тестировщики не смогут определить ожидаемый результат.

# Исправленная версия ТЗ

## Функционал корзины

1. Пользователь может добавить в корзину от 1 до 10 единиц одного товара за одну операцию.
2. Общее количество единиц одного товара в корзине не может превышать 10.
3. Пользователь может изменять количество товара в корзине в диапазоне от 1 до 10 единиц.
4. Для удаления товара из корзины пользователь использует кнопку “Удалить”.  
    При установке количества 0 товар автоматически удаляется из корзины.
5. В корзине может находиться не более 5 различных товаров одновременно.
6. Суммарное количество всех товаров в корзине не может превышать 20 единиц.
7. При попытке превысить ограничения система отображает соответствующее сообщение:
    - “Максимальное количество данного товара в корзине: 10”
    - “Максимальное количество разных товаров в корзине: 5”
    - “Максимальное общее количество товаров в корзине: 20”
8. На странице корзины отображаются:
    - название товара;
    - количество;
    - цена за единицу;
    - суммарная стоимость позиции, если товаров больше 1;
    - итоговая стоимость корзины.
9. Если цена изменилась в каталоге, система автоматически обновляет ее в корзине у всех пользователей. 
10. В корзине может отображаться рекламный блок с рекомендациями других товаров.
11. Рекламный блок отображается:
	- в будние дни;
	- с 08:00 до 11:00;
	- с 18:00 до 21:00;
	- по часовому поясу пользователя.
12. Если товар снят с продажи, пользователь должен увидеть уведомление “Товар {Название товара} недоступен для заказа”.
13. Если остаток товара стал меньше указанного в корзине, пользователь должен увидеть уведомление “Остаток товара {Название товара} меньше добавленного в корзину, уменьшите количество товара или ожидайте поступления”.
14. При изменении количества товара или состава корзины итоговая стоимость пересчитывается автоматически.
